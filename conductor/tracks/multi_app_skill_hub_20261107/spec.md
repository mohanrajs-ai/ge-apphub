# Specification: Multi-App AI Skill Hub (Dev-to-Registry-to-Multi-App Governance Pipeline)

## 1. Overview
Transform the Skills Governance module into a complete **Multi-App AI Skill Hub** where:
1. **Skill Development on Dev App:** All skill authoring happens on a designated Dev GE App (e.g., `service-desk-app-01`, configurable via `DEV_SKILL_ENGINE_ID`). When the author clicks **Share** in the Dev GE App and selects target Cloud Identity / M365 group(s), Discovery Engine puts the skill into `PENDING_REVIEW` (`state=DISABLED`, `hasActiveIamProposals=true`).
2. **Automatic Trigger on Admin Approval Pending:** Background sync detects the pending skill on the Dev App and automatically initiates the **6-Stage Multi-App AI Skill Hub Pipeline**.
3. **Environment Templatization:** Automatically converts Dev-app-specific resource paths and data store IDs in `SKILL.md` into portable template variables (`{{engine_id}}`, `{{project_number}}`, `{{location}}`, `{{app_knowledge_datastore_id}}`).
4. **Connector Requirement Discovery:** Parses `SKILL.md` to identify every required 1P M365 / enterprise data connector (e.g., `outlook-calendar`, `outlook-email`, `teams`, `onedrive`, `sharepoint`, enterprise knowledge datastore) and compares them against each target GE App's live `dataStoreIds`.
5. **Group-to-Target-App Resolution:** Maps the requested group names from `iamProposals` (e.g., `finance-app-01-users@...`, `ge-hr-users@...`, or `global-skills@...`) to the exact target GE Apps (`target_engines`) and scope (`SINGLE_APP`, `MULTI_APP`, `GLOBAL`).
6. **Multi-App Evaluation & Token Optimization:** Runs `SkillEvaluationAdkAgent` across **every resolved target GE App**, validating template rendering, connector availability on each target engine, structural rubric (`0-100`), and token optimization (`discovery_tokens`, `total_tokens`, `optimized_total_tokens`, `tokens_saved`, `efficiency_grade`).
7. **Automated InfoSec Security Scan:** Runs `InfoSecAdkAgent` to verify prompt-injection guardrails, cross-app data boundary safety, secret scanning, and least-privilege IAM roles.
8. **Manual InfoSec Security Approval Gate:** Sends the InfoSec review notification email and pauses at `AWAITING_INFOSEC_APPROVAL`, allowing the InfoSec reviewer in the Skill Hub UI to inspect the Per-App Eval & Connector Readiness Matrix, adjust target apps if needed, and click **Approve & Distribute** or **Reject**.
9. **Agent Platform Skill Registry Publication & Multi-App Distribution:** Publishes the templatized `SKILL.md` archive to the live **GCP Agent Platform Skill Registry** (`agentregistry.googleapis.com`), applies Registry IAM policy, and distributes the rendered skill (`{{engine_id}}` resolved per app) to each approved target GE App (`discoveryengine.googleapis.com`).
